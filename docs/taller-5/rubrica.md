# Rúbrica del Taller 5

Fuente: criterios y ponderaciones comunicados por el usuario durante esta corrección. No se presenta este archivo como copia de una rúbrica externa no inspeccionada.

| Criterio | Peso |
|---|---:|
| Calidad del código | 25 % |
| Sistema de agentes | 20 % |
| Diagramas de estructura y flujo | 20 % |
| Herramientas, permisos y modelo | 15 % |
| Diferencias con el sistema de referencia | 10 % |
| Documento | 10 % |

El documento PDF debe tener como máximo ocho páginas y cuatro secciones: proyecto y herramienta; sistema de agentes; calidad del código; diferencias con el sistema de referencia.

La referencia no está disponible. El usuario autorizó continuar con la implementación y marcar esa comparación como pendiente. No se asigna puntuación ni se afirma cumplimiento total del criterio sin inspeccionarla. `entrega.md` es el texto de entrega y `taller5.pdf` su versión breve con diagramas vectoriales.
