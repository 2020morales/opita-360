# Entorno de trabajo — OPITA 360

- **Editor:** Visual Studio Code.
- **Frontend:** React y Vite (JavaScript/CSS).
- **Backend:** Python con FastAPI y Uvicorn.
- **Control de versiones:** Git y GitHub.
- **Base de datos prevista:** PostgreSQL. Se incluye `database/schema.sql`; la versión de demostración todavía utiliza datos en memoria.
- **IA sencilla:** recomendador por reglas que compara intereses, duración y presupuesto. No requiere modelo propio ni suscripción paga.
- **Asistencia de IA para desarrollo:** se puede usar ChatGPT en modalidad disponible para el estudiante; las funciones básicas del proyecto no dependen de una API paga.
